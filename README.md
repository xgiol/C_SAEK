# Γλώσσα Προγραμματισμού Ι (C11) — Αλγοριθμική και Δομές Δεδομένων

Πλήρες εκπαιδευτικό υλικό για ένα εισαγωγικό, 15-εβδομάδων μάθημα
προγραμματισμού σε C (πρότυπο C11) για **απόλυτους αρχάριους**, το οποίο
λειτουργεί ταυτόχρονα και ως εισαγωγή στην αλγοριθμική σκέψη και τις βασικές
δομές δεδομένων. Βασίζεται στο πρόγραμμα σπουδών "Τεχνικός Εφαρμογών
Πληροφορικής" (ΔΣΑΕΚ).

Το μάθημα αποτελείται από **1 ώρα θεωρίας** και **5 ώρες εργαστηρίου** την
εβδομάδα, επί 15 εβδομάδες.

## Δομή του αποθετηρίου

```
.
├── notes/            Πλήρεις σημειώσεις θεωρίας σε ένα ενιαίο .docx (Ελληνικά)
├── slides/            15 παρουσιάσεις PowerPoint (μία ανά εβδομάδα, Ελληνικά)
├── exercises/         15 φύλλα ασκήσεων εργαστηρίου (Markdown, Ελληνικά)
├── src/                Πηγαίος κώδικας ΟΛΩΝ των παραδειγμάτων/λύσεων,
│                       οργανωμένος ανά εβδομάδα (weekNN/), σε Greeklish
│   ├── week01/ ... week15/
│   │   ├── *.c                 Παραδείγματα/επίδειξη θεωρίας
│   │   └── exercises/*.c       Ενδεικτικές λύσεις των ασκήσεων εργαστηρίου
├── docs/
│   ├── BUILD.md         Αναλυτικές οδηγίες μεταγλώττισης (Windows/macOS/Linux)
│   └── IDE_SETUP.md     Προτεινόμενο compiler/IDE setup (MacBook + εργαστήριο Windows + Ubuntu)
└── CMakeLists.txt      Ενιαίο σύστημα χτισίματος για όλο τον πηγαίο κώδικα
```

## Γρήγορο ξεκίνημα (μεταγλώττιση όλου του κώδικα)

Ίδιες εντολές σε **Windows, macOS και Linux** (βλ. [`docs/BUILD.md`](docs/BUILD.md)
για αναλυτικές οδηγίες εγκατάστασης εργαλείων, και [`docs/IDE_SETUP.md`](docs/IDE_SETUP.md)
για προτεινόμενο συνδυασμό compiler/IDE σε MacBook + εργαστήριο Windows + Ubuntu):

```bash
cmake -S . -B build
cmake --build build
```

Κάθε αρχείο `.c` γίνεται ξεχωριστό εκτελέσιμο μέσα στο `build/bin/weekNN/`.

## Γλώσσα υλικού

- **Σημειώσεις, παρουσιάσεις, εκφωνήσεις ασκήσεων:** Ελληνικά.
- **Σχόλια και μηνύματα (`printf`/`scanf`) μέσα στον πηγαίο κώδικα:**
  **Greeklish** (λατινικοί χαρακτήρες), σκόπιμα — ώστε να αποφεύγονται
  προβλήματα κωδικοποίησης χαρακτήρων ανάμεσα σε διαφορετικά λειτουργικά
  συστήματα, τερματικά και IDE (Windows/macOS/Linux, Code::Blocks, VS Code,
  online compilers κ.λπ.). Τα ονόματα μεταβλητών/συναρτήσεων είναι επίσης σε
  Greeklish, ώστε ο κώδικας να είναι αναγνώσιμος από Ελληνόφωνους μαθητές
  χωρίς κίνδυνο ασυμβατότητας.

## Άδεια χρήσης / Πηγή υλικού

Το υλικό αυτό βασίζεται στις προσωπικές σημειώσεις και ασκήσεις του
εκπαιδευτή για το μάθημα "Γλώσσα Προγραμματισμού Ι (C11) — Αλγοριθμική και
Δομές Δεδομένων" και αναδιοργανώθηκε/επεκτάθηκε με τη βοήθεια AI εργαλείου.
Ελεύθερο για εκπαιδευτική χρήση εντός του πλαισίου του μαθήματος.

## Κατάσταση - "Έργο εν εξελίξει"

Αυτό είναι υλικό σε εξέλιξη. Θα δημιουργείται αυξητικά με βάσει το πρωτογενές 
υλικό και ότι διδάσκεται στην τάξη κατά τη διάρκεια του εξαμήνου. Προτεινόμενα
επόμενα βήματα για όποιον θέλει να αξιοποιήσει το υλικό στην τάξη:

- Διαβάστε/επιμεληθείτε τις σημειώσεις (`notes/`) και τις παρουσιάσεις
  (`slides/`) — ιδιαίτερα το ύφος και το επίπεδο λεπτομέρειας ανά εβδομάδα 
  ανάλογα με τις ανάγκες σας.
- Οι λύσεις ασκήσεων σε `src/weekNN/exercises/` είναι ενδεικτικές, ίσως θελήσετε 
  να τις κρύψετε από τους μαθητές αρχικά. Θα προστίθενται σταδιακά στο αποθετήριο.
- Ελέγξτε ξανά τη σειρά/βάθος ύλης ανά εβδομάδα σε σχέση με τον πραγματικό
  ρυθμό της τάξης σας.
