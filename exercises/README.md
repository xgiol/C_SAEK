# Ασκήσεις Εργαστηρίου — ανά Εβδομάδα

Κάθε αρχείο `weekNN_askiseis.md` περιέχει 6–8 μικρές ασκήσεις προγραμματισμού,
διαβαθμισμένης δυσκολίας, σχεδιασμένες να λυθούν **μέσα στην τάξη** κατά τη
διάρκεια του εργαστηρίου, αμέσως μετά τη θεωρία της αντίστοιχης εβδομάδας.

Ενδεικτικές λύσεις υπάρχουν στο `src/weekNN/exercises/askXX_*.c` (σε
Greeklish σχόλια/μηνύματα, όπως όλος ο πηγαίος κώδικας του μαθήματος) και
χτίζονται αυτόματα μαζί με όλο το υπόλοιπο project μέσω του CMake.
