# Δραστηριότητες Εβδομάδας 1 (δεν μεταγλωττίζονται)

Τα αρχεία σε αυτόν τον φάκελο **δεν** συμπεριλαμβάνονται στο CMake build,
επειδή είναι σκόπιμα «χαλασμένα» — είναι ασκήσεις για το χαρτί/τάξη:

- `askisi_diorthosis_syntaktikwn_lathwn_BROKEN.c`: Λείπουν ερωτηματικά και
  εισαγωγικά. Ζητήστε από τους μαθητές να βρουν και να διορθώσουν όλα τα
  συντακτικά λάθη ώστε το πρόγραμμα να μεταγλωττιστεί.
- `askisi_sosti_seira_grammwn_ANAKATEMENO.c`: Οι γραμμές του προγράμματος
  είναι σε τυχαία σειρά. Ζητήστε από τους μαθητές να τις βάλουν στη σωστή
  σειρά ώστε να τυπώνεται "I love love love programming!" και να
  χαρακτηρίσουν κάθε γραμμή (οδηγία προεπεξεργαστή, δήλωση μεταβλητής,
  εκτελέσιμη εντολή, εντολή return, συνάρτηση main).

Οι λύσεις τους μπορούν να μπουν στο `src/week01/` (π.χ.
`05_diorthomeno.c`) αφού ολοκληρωθεί η άσκηση στην τάξη.
